# Nexus Launcher Website

GitHub Pages-ready static website for Nexus Launcher.

## Setup

1. Upload the contents of this folder to your GitHub repository.
2. Open `config.js`.
3. Replace `YOUR-USERNAME/YOUR-REPOSITORY` with your GitHub repository path.
4. Create a GitHub Release in that repository and upload your launcher ZIP with the exact filename `NexusLauncher.zip`.
5. Enable GitHub Pages from **Settings → Pages → Source: GitHub Actions**.

The download buttons use the GitHub Releases `latest/download` URL, so you do not need to store the launcher ZIP inside the Pages site itself.
